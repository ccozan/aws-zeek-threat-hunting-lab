# SOC Investigation: Potential HTTP Beaconing

## Investigation Overview

This investigation analyzes suspicious periodic HTTP communication identified during threat hunting with Zeek network telemetry and Splunk Enterprise.

A Potential HTTP Beaconing detection identified repeated communication from an internal host to a single external destination. The investigation pivoted across Zeek `conn.log`, `http.log`, and `files.log` telemetry to determine the frequency, duration, volume, and characteristics of the activity.

## Step 1 – Establish the Timeline

The investigation began by determining how long the communication persisted.

Splunk identified:

- **First Seen:** 2020-06-04 17:01:28
- **Last Seen:** 2020-06-05 17:01:02
- **HTTP Events:** 2,882

The source communicated repeatedly with the same destination for approximately 24 hours.

---

## Step 2 – Analyze Connection Activity

Zeek `conn.log` telemetry was analyzed for the source/destination pair.

Results included:

| Metric | Result |
|---|---:|
| Connections | 2,883 |
| Bytes Received | 652,015,034 |
| Average Connection Duration | 0.71 seconds |
| Maximum Connection Duration | 90.50 seconds |

The traffic consisted primarily of repeated short-lived connections to the same external destination.

Earlier beaconing analysis identified an average interval of approximately **29.98 seconds**, with a standard deviation of approximately **2.14 seconds** and a regularity measurement of approximately **0.071**.

The highly periodic timing warranted additional investigation for automated communication.

---

## Step 3 – Analyze HTTP Activity

The investigation pivoted into Zeek `http.log`.

Results showed:

- **2,882 HTTP events**
- **2,882 unique connection IDs**
- Destination port **80**
- Source `192.168.99.53`
- Destination `67.207.93.135`

This indicated repeated individual HTTP connections rather than thousands of events generated by one persistent HTTP session.

---

## Step 4 – Analyze File Transfer Activity

Zeek `files.log` was analyzed to determine whether content was transferred during the HTTP communication.

Results included:

| Metric | Result |
|---|---:|
| File Events | 2,882 |
| Unique File IDs | 2,882 |
| MIME Type | `text/plain` |
| Smallest Observed Transfer | 2,920 bytes |
| Average Observed Transfer | 224,739.37 bytes |
| Largest Observed Transfer | 226,132 bytes |
| Total Observed Bytes | 647,698,872 |

Multiple visible events showed repeated `226,132` byte transfers occurring approximately every 29–30 seconds.

A raw `files.log` event independently confirmed HTTP communication from `192.168.99.53` to `67.207.93.135:80` involving a `text/plain` transfer of `226132` bytes.

---

## Step 5 – Cross-Log Correlation

A Splunk search correlated events containing the source and destination across:

- `zeek:conn`
- `zeek:http`
- `zeek:files`

The search returned **8,647 events** across the three telemetry sources.

This provided multiple forms of network evidence associated with the same source/destination pair.

An attempted pivot using an individual Zeek connection UID did not return searchable results in the indexed dataset. Therefore, the investigation did not claim successful UID-level correlation across all three logs.

## MITRE ATT&CK Mapping

### T1071.001 – Application Layer Protocol: Web Protocols

The observed behavior is potentially consistent with the use of web protocols for command-and-control communication because the host repeatedly communicated with an external destination over HTTP.

The network telemetry alone does not establish that command-and-control occurred, so this mapping represents a potential behavioral association rather than confirmation of malicious activity.

---

## Analyst Conclusion

Investigation of the Potential HTTP Beaconing alert identified persistent outbound HTTP communication from `192.168.99.53` to `67.207.93.135` over TCP port 80.

Zeek telemetry showed 2,882 HTTP events occurring at an average interval of approximately 29.98 seconds with low timing variation, indicating highly periodic network behavior. Analysis of `files.log` also identified 2,882 file events associated with the source/destination pair, including repeated `text/plain` transfers of 226,132 bytes.

A final correlation search identified 8,647 events across `zeek:conn`, `zeek:http`, and `zeek:files`.

The combination of persistent communication with a single external destination, regular approximately 30-second intervals, repeated HTTP activity, and consistent data-transfer characteristics is suspicious and consistent with behavior that can be observed in automated beaconing or command-and-control communications.

The available network telemetry does not by itself prove that the destination is malicious or establish a specific malware family. The alert should therefore be escalated for additional endpoint and threat-intelligence investigation.

---

## Recommended Response Actions

1. Investigate the process responsible for connections from `192.168.99.53`.
2. Review endpoint telemetry for suspicious process execution or persistence.
3. Perform reputation and threat-intelligence analysis on `67.207.93.135`.
4. Correlate the network activity with endpoint process and DNS telemetry.
5. Preserve relevant PCAP, Zeek logs, and endpoint evidence.
6. Consider isolating the endpoint if additional evidence confirms malicious activity.
7. Block or restrict the destination if malicious infrastructure is confirmed.
